# App Store Connect OpenAPI spec (pinned)

`openapi.oas.json` is Apple's official App Store Connect OpenAPI specification, committed unmodified.
It is the source of truth for:

- `src/openapi/schema-index.json`, the runtime operation index used by the `asc_api_*` tools
  (generated by `scripts/generate-openapi-index.ts`)
- the request contract checks in `tests/helpers/contract.ts`
- `scripts/spec-sheet.ts`, which prints resolved operation shapes

It is not shipped in the npm package.

## Updating

1. `npm run update-openapi` downloads the latest archive, replaces `openapi.oas.json`, regenerates the
   index, and prints the new SHA-256.
2. Update the snapshot section above.
3. Run `npm test`; contract failures point at tools whose requests no longer match the spec.

Known gaps where the live API accepts more than the published spec are patched for tests only in
`SPEC_OVERRIDES` (`tests/helpers/contract.ts`), each with its source.
